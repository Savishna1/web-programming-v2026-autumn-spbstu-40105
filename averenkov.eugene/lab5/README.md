# Лабораторная работа 5

## Задание

Задача 5. Реализовать слайдер книг в книжном интернет-магазине. Создать слайдер
на главной странице магазина, состоящий из карточки книги. Карточка должна
содержать обложку книги, название, рейтинг, описание и цену. Функционал
слайдера: кнопки «Далее» и «Назад»; подпись текста к каждому слайду; вывод
номера и максимального количества (1/3, 2/3, 3/3); пагинация (при клике —
переключается на нужный слайд).

## Реализация

Слайдер реализован на React с использованием сборщика Vite. Данные о книгах
хранятся в массиве `books` внутри компонента `Slider`. Номер текущего слайда
хранится в состоянии через хук `useState`. Переключение слайдов выполняется
функцией `show`, которая меняет состояние и зацикливает переходы: после
последнего слайда идёт первый, перед первым — последний. Кнопки «Назад» и
«Далее», а также клики по точкам пагинации вызывают `show` с нужным индексом.
React автоматически перерисовывает интерфейс при изменении состояния. Стили
подключены через `import './style.css'`. Обложки книг лежат в папке `public` и
доступны по адресам `/1.svg`, `/2.svg`, `/3.svg`.

Структура проекта:

- `index.html` — точка входа, содержит контейнер `<div id="root">`;
- `src/main.jsx` — монтирует компонент `App` в корень;
- `src/App.jsx` — корневой компонент, рендерит `Slider`;
- `src/Slider.jsx` — сам слайдер с карточкой книги, кнопками, счётчиком и
  пагинацией;
- `src/style.css` — стили;
- `public/1.svg`, `public/2.svg`, `public/3.svg` — обложки книг.
