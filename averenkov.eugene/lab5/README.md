# Лабораторная работа 5: слайдер книг

Слайдер книг на главной странице книжного интернет-магазина (React + Vite).

Карточка книги: обложка, название, рейтинг, описание, цена.

Функционал:
- кнопки «Назад» и «Далее» (по кругу);
- подпись к каждому слайду;
- номер слайда и общее количество (1 / 4);
- пагинация: клик по точке открывает нужный слайд.

## Запуск

```
npm install
npm run dev
```

Открыть адрес, который выведет Vite (обычно http://localhost:5173).

## Сборка

```
npm run build
```

## Структура

- `index.html` - точка входа, контейнер `#root`
- `src/main.jsx` - данные о книгах и React-компонент слайдера
- `src/styles.css` - стили
- `assets/` - обложки книг
- `vite.config.js` - настройка Vite
- `package.json` - зависимости и скрипты
